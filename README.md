# Ultrasonic Range Detector Using 8051

A simple and practical distance measurement system designed using an **8051 microcontroller, HC-SR04 ultrasonic sensor, 16×2 LCD, and buzzer**.

The system measures the distance of an object using the **pulse-echo method** and displays the measured distance on an LCD. A buzzer is activated when an object is detected within **10 cm**. The project demonstrates the practical application of **microcontroller programming, ultrasonic sensing, and Assembly language**.

## Key Features

* Measures object distance using an ultrasonic sensor
* Real-time distance display on a 16×2 LCD
* Buzzer alert when distance is ≤ 10 cm
* Based on the 8051 microcontroller
* Programmed using Assembly language
* Simulated and tested using Proteus
* Useful for learning sensor interfacing and embedded systems
